# Adselams Website Clone

This repository contains a complete static clone of [Adselams](https://adselams.com/), including all pages, subpages, styling, scripts, and media assets.

## Structure
- `index.html` - Homepage
- `about-us/`, `contact-us/`, `services/`, `project/`, etc. - Subpages and categories
- `wp-content/` - Uploads, CSS, JavaScript, and fonts assets
